# q6y6y6.github.io

Personal homepage for `q6y6y6`, built as a dependency-free static site for GitHub Pages.

## Run locally

From this directory, start any static server, for example:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Publish to GitHub Pages

1. Create a public repository named `q6y6y6.github.io` under the `q6y6y6` account.
2. Push the files in this directory to the repository's `main` branch.
3. In GitHub, open `Settings > Pages` and choose `Deploy from a branch`, branch `main`, folder `/ (root)`.
4. Open `https://q6y6y6.github.io` after the Pages deployment completes.

## Personalize before publishing

- Replace the draft introduction in `index.html` with your name, role, and research interests.
- Replace `your-email@example.com` with a real public contact address.
- Add more projects by duplicating the project section and changing its links and description.
- Keep the LightX2V description accurate because the repository is currently the main public project on the account.
